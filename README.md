# Emerald 三网定制主题

基于 [Tokinx/Emerald](https://github.com/Tokinx/cf-server-monitor-theme-emerald) 的 CF Server Monitor 自用三网主题。保留原版外观，电信、联通、移动独立显示延迟和丢包。当前版本 **v1.2.14**。

只修改主题，不修改 CFSM Worker、探针或服务器配置，不自动切换线上主题。

## 安装 / 升级

后台 → 主题商店 → 自定义主题 URL：

```text
https://github.com/lll33lll/cf-server-monitor-theme-emerald/tree/50affe93d93ad21ed987951af94524f6d9c4956e
```

也可刷新你自己的后台，在 **Emerald · 自用三网版** 中加载版本、选择新版并切换。

滚动构建地址：

```text
https://github.com/lll33lll/cf-server-monitor-theme-emerald/tree/build
```

源码在 [`custom`](https://github.com/lll33lll/cf-server-monitor-theme-emerald/tree/custom)，安装产物在 `build`；`main` 保留上游基线与本说明。不要填写源码分支。

商店读取 `build` 的最新构建提交，条目无需重复添加；已应用的固定 SHA 不自动更新。后端通常缓存分支约 1 小时、固定 SHA 约 24 小时，升级建议换新 SHA，避免旧资源混用。

## 为什么黄柱上方有一点红？

**柱身代表均值，顶部点代表较高色档的峰值。** 比如这一格平均 238 ms、峰值 241 ms，柱身黄色、顶部点红色；不是颜色粘连，也不是把峰值冒充平均延迟。

只有峰值跨入更高色档时才显示点，同色档不重复标注。点柱子可以同时查看平均和峰值。延迟色阶仍为 60 / 120 / 180 / 240 ms，没有改阈值或强制锁红。

## v1.2.14 改进

- 峰值从贴在柱身上的色帽改为**分离的顶部小点**，补充“柱身均值 / 顶部峰值”图例。
- 柱身选中时的放大与峰值点分开处理，避免点跟着放大后碰到上一行文字；气泡关闭时选中状态同步恢复。
- 气泡按手机实际可见区域约束位置和宽度；缩放、视口变化、滚动时及时收起，防止气泡留在旧位置。
- 拖动时定位合并到每帧一次，避免重复测量和重绘。
- 修复鼠标悬停但未聚焦时 Esc 不能收起的问题，补齐指针捕获释放和卸载清理。
- 历史请求未完成时共享同一次请求；15 秒缓存从成功完成时计算，旧请求失败不误删新请求缓存。
- 历史请求 30 秒超时后可重新请求；畸形或不合理的时间戳记录忽略，不污染曲线。

这些是显示、交互和请求稳定性修复，**没有改变三网均值、峰值、丢包率的计算口径**。

## 保留的功能与 v1.2.13 修复

- 卡片为延迟 / 丢包两块面板，分别竖排电信、联通、移动；列表独立两列。
- 每条线路 20 格，优先读取后台窗口时长，默认 2 小时；卡片和列表共用整分钟时间轴。
- 点柱子就地显示时间与数值，横向滑动切换，抬手保留 2.5 秒；不再弹历史曲线卡片。支持悬停和键盘操作。
- WS 延迟与丢包独立合并，省略字段不清空另一项。接收时立即累积变化，与一秒视觉播放解耦，不再漏掉批次中间样本。
- 紧凑 v2 缓存兼容旧版有效样本，保留窗口外 15 分钟衔接；隐藏 / 关闭页面及时保存。
- 同源、同一浏览器存在 LuminaPlus 缓存时只读接续，不修改或删除它的存储；不同浏览器、域名仍独立。
- 每 5 分钟同步现有聚合服务器快照，重连 / 回前台同步；首页不新增逐节点历史轮询。
- 详情曲线不再把 8 条线路共用历史截成合计 500 条；资源与 Ping 图复用同档历史请求，并用已有历史回填探测缓存。
- 资源历史不造 15 分钟空槽，未提供的流量计数保持缺测、不补 0；旧请求不覆盖新节点 / 新档位，增量资源字段不误清零。

## 数据语义与限制

数字按有效覆盖时间加权，不混算三网，不简单平均 20 个百分比。缺测为 `—` / 灰柱，真实 100% 丢包为红柱、延迟缺测；极小非零丢包显示 `<0.1%`。丢包热力色仍为 0% 绿、3% 黄、10% 橙、30% 及以上红。

时间窗口滚动、旧事件过窗时，标记自然退出。后台抽样和页面未运行时的缺口无法由主题凭空补回；可用历史并非完整逐包历史。隐私模式 / 配额不足时内存采样仍工作，但刷新后不保证保留。

支持后台自定义线路名、显示开关及原版背景 / 公告 / 价格配置；关闭三网详情时显示实时数字，不画历史柱。完整配置 JSON 见 [上游说明](https://github.com/Tokinx/cf-server-monitor-theme-emerald/blob/main/README.md)。

## 开发与校验

`custom` 分支，Node 24 + Bun 1.3.14：

```bash
bun install --frozen-lockfile
bun run lint
bun run build
```

产物在 `dist/`，Actions **Publish Three-Net Theme** 更新 `build`，不会自动应用到你的 CFSM。

本版通过代码、类型、生产构建、静态资源核对，并检查了慢请求共享、完成后缓存、超时重试、异常历史过滤和可见视口边界。此前探测回放校验保留。这不替代用户浏览器的实际验证。
